# Tienda Bora World

Primera preentrega del proyecto. Herramienta de consola desarrollada en Node.js para consumir la API FakeStore.

## Requisitos previos
- Node.js v18 o superior

## Comandos disponibles

Consulta de todos los productos        npm run start GET products

Consultar producto por ID              npm run start GET products/7

Crear nuevo producto                   npm run start POST products T-Shirt-Rex 300 remeras

Eliminar un producto por ID            npm run start DELETE products/7

## Instalación
